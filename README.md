# SQL 

This repository covers **10 essential SQL concepts** from basics to advanced, designed to build strong database and query skills.

---

## 1. Creating and Populating Tables

* Defined tables using `CREATE TABLE`
* Inserted data using `INSERT INTO`
* Retrieved data using `SELECT`

---

## 2. Filtering and Sorting

* Used `WHERE` for filtering
* Applied `ORDER BY` for sorting
* Combined conditions with `AND` / `OR`

---

## 3. Aggregation and Grouping

* Used `COUNT`, `SUM`, `AVG`
* Grouped data with `GROUP BY`
* Filtered groups using `HAVING`

---

## 4. Multi-Table JOINs

* Created related tables
* Used `INNER JOIN` and `LEFT JOIN`
* Combined data across tables

---

## 5. Subqueries

* Used subqueries in `WHERE` and `SELECT`
* Learned correlated vs non-correlated queries

---

## 6. Date and Time Functions

* Used `DATEDIFF`, `DATE_ADD`, `CURDATE`
* Filtered data by date ranges
* Formatted date outputs

---

## 7. Window Functions

* Applied `ROW_NUMBER`, `RANK`, `DENSE_RANK`
* Used `PARTITION BY` and `ORDER BY`
* Used `LEAD` and `LAG` for row comparison

---

## 8. CTEs and Recursive Queries

* Used CTEs for cleaner queries
* Built recursive queries for hierarchical data

---

## 9. Stored Procedures & Functions

* Created reusable procedures with parameters
* Built user-defined functions for calculations

---

## 10. Database Design & Optimization

* Designed normalized schema (eCommerce)
* Applied indexing for performance
* Implemented triggers and transactions
* Created views for simplified queries
